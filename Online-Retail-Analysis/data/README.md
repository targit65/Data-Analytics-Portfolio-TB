# Dataset Information

The original online retail marketplace dataset is not included in this repository because of GitHub's individual file-size upload limit.

The dataset was used locally for data auditing, cleaning, exploratory data analysis, SQL analysis and Power BI dashboard development.

## Dataset Details

- Original file: `Test_Pandas.csv`
- Records: 464,433
- Data type: Marketplace listing-level data
- Key fields: Item ID, Shop ID, Category, Price, Stock, Sold Count and Item Creation Date.
- The sample CSV contains a subset of the processed dataset.
- The complete processed dataset is 395 MB and not hosted on GitHub.
